# AgentTeams v0.1.22-rc.2

Preview release on npm `next`, adapting this project to the published DeepSeek Harness desktop **`0.2.0-rc.2`** release. The recommended host is now Harness `0.2.0-rc.2`.

- Accept `0.2.0-rc.2` in every declared DSH host peer range, alongside the previously supported targets. No exact-version exemption is required.
- Move the development baseline, all pnpm overrides and the compatibility policy to `0.2.0-rc.2`. The override set is the exact package closure the desktop application ships, verified package by package.
- `0.1.7-rc.2` stays a supported target and moves to the legacy track.
- Keep `0.2.0` recorded as a source candidate rather than a published host target.

## Install

In the desktop Add Plugin field, enter `@nanmicoder/dsh-agent-teams@0.1.22-rc.2`. An npm website URL is not a package specification.

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.22-rc.2
```

Restart the active Harness profile and refresh its Web UI. This preview does not change npm latest.
